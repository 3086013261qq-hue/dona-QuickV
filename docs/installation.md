# 快速 V 0.6.5 · dona美化 0.1.0：私有测试安装

这是一份完整的二改 CJS 安装器交付，沿用原版 SillyDroid ARM64 安装架构。不是 APK 重打包，也不是酒馆 ZIP 数据导入包。首次安装及更新所需的原版运行环境、Python 依赖仍由安装器从原版固定 HTTPS 地址下载，全部保留原版大小及 SHA-256 校验。因此交付 ZIP 不是离线运行环境包。本次开发没有执行原始或二改安装器，没有访问本机业务配置或凭据。

## 本地构建与核验

需要 Python 3.12+、Node.js 18+（仅语法与回归检查）。原始 `install-0.6.5.cjs` 放在仓库根目录，必须匹配 SHA-256 `95f944ba5483e8953bab59a8962cc04d5517fddee6f5913a1054d16db6137db5`。

```powershell
python tools/build_release.py install-0.6.5.cjs
python -m unittest discover -s tests -v
node --test tests/security.test.cjs
python tests/browser_qa.py
```

浏览器检查依赖 `requirements-dev.txt` 的固定版本 Playwright 与其 Chromium。缺少时可手动安装：`python -m pip install -r requirements-dev.txt`，然后 `python -m playwright install chromium`。这是开发测试依赖，不加入手机版运行时。

输出默认位于工程的 `.local/release/`，包括：

- `quick-v-0.6.5-dona-0.1.0-private.zip`：本地传递包。
- `install-quick-v-0.6.5-dona-0.1.0.cjs`：完整二改安装器。
- `dona-broadcast.js`：独立酒馆助手脚本。
- `SHA256SUMS`、`build-report.json`、上游许可证和说明。
- `payload/`、`overlay/`、`panel/`：仅供本地审查的解包目录，不需要复制到手机。

原安装器、整个 `.local/` 及生成的安装包均已被 Git 忽略。不要用 `git add -f` 上传。构建仅解析 JSON、验证 Base64 和摘要、静态替换资源；不会导入、require 或执行安装器。

## 手机安装与更新

1. 用 SillyDroid 自身的数据备份功能先保留可恢复备份，并在本机保存当前原版安装器。不要将包含凭据或聊天的备份发到仓库或聊天中。
2. 将二改 CJS 作为本地文件复制到手机，在电脑或手机核对 `SHA256SUMS` 中对应摘要。可用 `sha256sum install-quick-v-0.6.5-dona-0.1.0.cjs`，与文本清单逐字比较。
3. 在原版快速 V 面板中停止服务。旧版 0.6.2 地区统计的特别处理、运行锁、空间与进程检查继续使用原版逻辑；如安装器要求先保存统计、再停止、重试，请按其提示操作。
4. 打开 **SillyDroid → 设置 → 内置终端**，进入复制文件所在目录，手动执行：

   ```sh
   node ./install-quick-v-0.6.5-dona-0.1.0.cjs
   ```

5. 等待原版下载、验证、事务安装结束，重启 SillyDroid 酒馆服务。从 **扩展设置 → 快速 V** 打开面板，确认标题「快速 V 0.6.5 · dona美化」。已有 Key、Cookie、聊天、角色及原业务接口由原版维护。

不要在 Windows、Termux、文件管理器或酒馆“数据管理 → ZIP 导入”中运行这个安装流程。不要使用匿名 CDN 导入私有仓库文件。安装器只有在你手动执行后才会下载原版依赖；没有加入新的远程安装脚本。

## 导入独立悬浮播报

在酒馆助手的脚本库中新建本地脚本，名称可填写「dona快V · 战术播报」，将 `dona-broadcast.js` 的完整源码复制到脚本编辑器并启用。不同酒馆助手版本的菜单与 iframe 权限需要在真机上核对；本项目不捏造未验证的宿主导入格式。

脚本需要访问同源父页面 DOM。禁止通过修改跨域权限来强行运行。二改原扩展仍须启用，才能从既有受保护状态链路获得本轮用量。只导入播报脚本、继续使用未适配原版时，自动退回 DOM 观察，无法获得本轮用量与可靠首包状态；不会补造统计。

普通流式、假流式、非流式和并发竞速均沿用原版。「已自动重试 n/m」直接来自原版请求预算，表示已开始的额外预算尝试，不包含首次请求；等待下一次重试时不会提前加一。「尝试 n/m」包含首次尝试；PVP 并发候选使用这个计数，不冒充串行重试。协议兼容回退可能使全局尝试数超过普通重试预算，此时省略尝试分母。没有实际状态时隐藏。完成默认 8 秒收起；最终失败保留到关闭或换轮。关闭只影响播报，不取消生成。

## 卸载美化与回滚

先在酒馆助手禁用或删除播报脚本，刷新酒馆页面。调试时也可在同源宿主页面执行 `window.__donaQvBroadcastV1?.()`，立即清理播报 DOM、样式、观察器、监听及计时器。原版提示和按钮始终保留。

若要完整移除 dona 管理面板及状态观察适配：停止快速 V，用此前保留且已核验的 **原版 0.6.5 安装器** 在同一内置终端手动重新安装并重启。原版安装架构会覆盖插件、扩展和应用代码；不要删除 `quick-v-state` 或手动编辑凭据。更早上游版本未做降级兼容验证，不建议作为回滚目标。

安装失败时保留原版事务回滚机制。如提示备份目录因回滚不完整而保留，不要删除该目录或继续强制安装。安装器对成功更新前的旧代码暂存会按原逻辑清理，所以成功后的撤回依赖你保存的原版安装器与本机备份。

如果要卸载整个快速 V，请使用上游已审核的卸载方式；本项目不提供删除原版运行环境、凭据和配置的命令。
