# v0.1.0-beta.2 · 安装与发布流程测试

此版本修正 beta.1 安装入口对原生 Android Node 构建的平台识别，接受 android/linux 两种平台值，仍要求 ARM64、Node.js 18+、toybox 和原 SillyDroid 环境/目录/锁校验。依据 [Node.js 官方 process.platform 文档](https://nodejs.org/api/process.html#processplatform)。beta.1 文件与摘要不覆盖；请使用本版本固定命令。

**全新安装资源阻塞：不能作为只有 SillyDroid 用户的完整可用安装交付。** 原作者正式下载地址在开发端普通 GET 返回 HTTP 403/连接错误。6 个运行包分片及 3 个代码包分片尚未获得，未核实正式备用源。详见随包 `resources.md` / `resource-status.json`。手机端可能有不同的访问结果，但未下载校验及真机安装前不宣称通过。

- 完整二改 CJS、固定入口、SHA256SUMS 和交付 ZIP：安装器具备全新安装路径，原运行包及依赖仍来自原作者，不另行分发；资源不可用时不跳过校验。
- 已装原版 0.6.5 的用户可先停止服务，精确校验原文件和运行环境后增量安装，不重新下载运行环境及 Python site；同版跳过，额外修改停止覆盖。
- 提供固定版本 install/status/restore 命令；restore 只还原本次修改的原版静态文件与删除新增 dona 模块，保留聊天、凭据、配置和酒馆目录。
- 酒馆助手使用可下载导入 JSON，经官方 ScriptTree/文件导入器格式核对，默认关闭；启用后由 jsDelivr 固定标签加载一次并核验源码 SHA-256，无更新轮询。
- 绒绒设计 UI、管理面板业务 app.js、认证、请求转发和重试保持既有实现；保留真实重试播报及 Token 结算。

README 提供完整命令和导入链接。导入 JSON 使用手机文件下载→酒馆助手脚本库导入，不需要复制完整 JS。原作者署名、许可证与第三方声明保留。公开二改分发授权已由仓库所有者确认并留存；不公开原始安装器，不重分发第三方运行环境。

自动化仅验证桌面与模拟文件系统/服务/宿主；安卓全新安装、实际资源下载与解包、后台生命周期、实际酒馆助手导入、真实服务商回归仍待验证。此版本为 Pre-release，不合并 main。
