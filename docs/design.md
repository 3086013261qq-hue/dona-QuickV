# dona快V / 设计层 v0.1

## 定位
手机优先的 Quick V 战术终端美化项目。以现成 Quick V 0.6.5 安装为外部依赖，主要自研交付物为酒馆助手美化脚本。电脑版作为可选兼容性参考，不主动修改现有后端。

## 架构
酒馆助手美化脚本 → 已安装的酒馆前端/管理面板 → 现有本地服务（独立安装、原配置不变）。
浏览器脚本不能假定具备本地进程或文件权限。管理页、iframe 与酒馆同源边界需要实测；若不能安全覆盖，则通过受支持的安装方式部署样式，不放宽安全限制。

## 视觉层
以明日方舟式工业终端为灵感，原创几何装饰，不使用官方素材。基色 #101216 / #1c2025；强调 #f5d449；正文 #edf0f3；警戒 #ff9390。直角、切角、细线、低动效，触控目标至少 44px。现有 v0.1 皮肤分面板和酒馆扩展两份覆盖 CSS。

## 里程碑
1. 归档参考版本、确认授权、固定适配基线。
2. 完成独立视觉层及本地预览，验证原控件不变。
3. 验证酒馆助手安装、卸载、更新方式及跨文档样式隔离；保留原版功能和安全边界。
4. 真机测试、视觉精修；只有明确缺失且确有需求的兼容功能才另行立项。后端优化不阻塞皮肤首发。
5. 完成授权核验、回归测试和签名/校验后的发布方案。

## 验收
无横向溢出，控件可操作，失败状态可辨认；未连接时显示真实未连接状态；卸载不损坏原版；凭据不出本地服务；无原任务存活时不得宣称可以续传。
