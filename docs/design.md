# dona快V / 设计层 v0.3

## 定位
基于 Quick V 0.6.5 的手机优先二改项目。成熟功能直接沿用；桌面版仅作为兼容性参考。自研重点为两套独立视觉层，不重写原后端、不改变既有配置。

## A. 管理面板替换
安装包中的 plugin/public/index.html 与 style.css 由 dona 版本替换；plugin/public/app.js 及后端接口保留，除必要的兼容适配外不改业务逻辑。保留原控件 ID、属性、表单行为、可访问性及安全边界。随 dona 安装包部署，酒馆原入口仍可打开管理面板，不依赖酒馆助手。

## B. 酒馆助手悬浮播报
独立、可选的前端脚本。观察原扩展已有的 #quick-v-chat-wait 与 #quick-v-failure-notice（含 data-phase）等状态节点；通过实际 DOM 及受支持事件更新播报，不新建后端轮询、不读写凭据、不触发生成/重试、不拦截请求。若未来存在稳定的公开状态事件接口，可采用事件订阅。原扩展继续运行。隐藏重复提示只能在悬浮窗成功接管展示时进行，卸载恢复，不能隐藏原版的必要操作控件。

## 视觉
明日方舟启发的原创工业终端风：#101216 / #1c2025 / #f5d449 / #edf0f3 / #ff9390。悬浮窗小巧，不遮挡聊天输入、生成/停止按钮；正常空闲时隐藏。状态仅显示原版可确认的等待、重试等待、继续生成、恢复、失败；未获知的状态不推断。无信息时不显示虚假倒计时。

## 开发顺序
1. 替换原版管理面板视觉，保留 app.js 行为和所有控件契约。
2. 实现独立酒馆助手悬浮播报脚本，验证脚本生命周期与宿主文档。
3. 在 mock 和安卓真机测试布局、状态更新、卸载还原及原版操作。
4. 核验授权与完整性校验，再打包发布。后端变动另行评估，不阻塞视觉交付。
