# dona快V 功能设计 / v0.1

状态：设计候选，尚未实现。首发手机优先；美化层独立；先适配、再优化。

| 模块 | 首发范围 | 验收 |
|---|---|---|
| F01 视觉主题 | 明日方舟启发式原创 CSS，保持原控件 | 320/390/430px、横屏、触控、无横向溢出，卸载还原 |
| F02 安装入口 | 酒馆助手只负责加载/卸载视觉层；后端独立安装 | 不使用浏览器脚本执行系统命令；若 iframe 无法合法覆盖，改用受支持的本地皮肤部署方式 |
| F03 连接与配置 | 展示本地服务状态，使用正式授权 API 的现有配置界面 | 密钥不进入美化脚本；失效/无权限如实提示 |
| F04 模型面板 | 依据能力矩阵显示合法模型及思考档位 | 不支持的选项不可选，切换模型不污染其他配置 |
| F05 生成状态 | 等待、首字、耗时、失败、停止、完成；速度和 token 仅在后端提供时展示 | 无数据为未知，不伪造实时指标 |
| F06 手机资源 | 隐藏页面停止非必要 UI 轮询，恢复时重读状态 | 计时器不泄漏；记录真机内存、CPU、耗电基线 |
| F07 可靠传输 | 后续后端版本实现有界缓存、授权请求恢复、去重及明确失效状态 | 模拟网络切换；无存活任务则不宣称无损恢复；用户停止不得自动重新请求 |
| F08 诊断 | 本地服务、网络连接、认证、限流及错误区分 | 报告脱敏，不记录对话、密钥、Cookie 或设备标识 |
| F09 维护 | 固定版本、完整性校验、配置迁移和回滚 | 更新失败原版本可用，不触碰角色卡和聊天数据 |
| F10 回归 | 合法消息格式、模型参数、流式/非流式、工具调用、生图兼容 | 使用 mock 服务与授权测试账号；不绕过服务端限制 |

## 开发顺序
A. 先做可独立使用的皮肤及真实原控件视觉预览。
B. 接入原版受支持的前端接口，验证酒馆助手边界。
C. 建立 PC mock 和安卓真机基线，修复已复现的缺陷。
D. 后端逐项升级正式 API 支持和移动可靠性；每项独立提交。
E. 审核授权、第三方声明、发布包和回退路径。

不在首版支持：私有控制台反代、自动收集会话凭据、配额或区域限制规避。没有明确数据的监控不做假演示。静静不得擅自重绘 UI。
