# dona快V 功能设计 / v0.2（范围修订）

## 主目标
基于现有 Quick V 0.6.5 运行环境，制作手机优先的明日方舟风酒馆助手美化脚本。原版已提供的功能作为既有依赖，不重新开发、不在美化层删除选项或修改请求行为。PC 上游只作为后续兼容性参考。

| 模块 | 首发范围 | 验收 |
|---|---|---|
| F01 视觉主题 | 原创战术终端 CSS，保留原控件 ID 和行为 | 320/390/430px、横屏、软键盘、触控 |
| F02 酒馆助手安装 | 可导入脚本，加载与卸载主题 | 不执行系统命令；同源边界内工作；卸载还原 |
| F03 管理面板 | 美化原有连接、模型参数、服务管理、等待与故障提示 | 原设置项不丢失，不改变业务逻辑 |
| F04 酒馆内提示 | 美化原有入口、弹窗、计时器及故障通知 | 状态来自原版，不伪造实时数据 |
| F05 版本维护 | 固定版本、兼容检测、主题恢复 | 不影响角色卡、聊天和原版安装 |

## 不阻塞首发
电脑端与手机端差异只在有明确需求时评估，优先复用公开、正式支持的能力。缓存、续传、后台进程、凭据与 API 转发均不属于皮肤脚本。原安装由用户独立管理，皮肤不读取凭据、不新增认证或转发逻辑、不改变服务端安全机制。

## 开发顺序
1. 审核已有 CSS 与原版实际 DOM。
2. 验证酒馆助手加载机制与管理面板 iframe 的同源关系。
3. 实现最小可安装/卸载美化脚本，若管理面板不允许访问则使用受支持的本地部署方式。
4. 视觉精修、真机验收与发布。静静不得擅自重绘 UI。
